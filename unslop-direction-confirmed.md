# Unslop Direction — Confirmed

## Direction (confirmed with user)

- **Product.** A student result management system that simplifies academic result workflows for students, teachers, and administrators — presented as a product to schools and colleges.

- **Character.** Genz yet professional — clean, modern, slightly vibrant but trustworthy. Not hype-filled, not corporate-stuffy. Designed to impress school administrators and appeal to younger users (teachers, students) while remaining authoritative for the institution.

- **World.** Academic institutional space — but updated for a modern era: digital records, classroom dashboards, administrative workflows that feel current not legacy. The world sets the tint of neutrals and the single accent color.

- **Moments.** One polished element carrying the color and craft — e.g., a beautifully rendered result card or chart showing plausible academic data, or a key visual from the modern academic world placed deliberately. Not a glowing blob, not a decorative orb.

- **Signature.** One small detail only this product would have — e.g., a status dot for published results presented as a clean badge, or keycap-style number formatting. One detail, used consistently, not five.

- **Color palette.** Light theme: warm neutrals (off-white/cream base), cool accent (NOT red, NOT peach, NOT the current `--primary: #f17a7e`). A professional accent suitable for schools/colleges — perhaps a muted blue, teal, or sage green. Dark theme: optional, muted, not using the current crimson ramp. If kept, must be genuinely improved not just a color swap.

- **Remove.** All ambient glow blobs, hero-glow, radial gradient background washes, decorative filler. The page should feel calm and structured, not glowing.

Nine passes will follow: Spacing → Color → Icons → Copy → Type → Layout → Details → Visuals → Motion.
